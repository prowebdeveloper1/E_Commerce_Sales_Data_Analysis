## E-Commerce Sales Data Analysis

This project is a Python-based data analysis project focused on analyzing e-commerce sales data and extracting meaningful business insights. The objective of the project is to understand sales performance across different products, categories, cities, and time periods.

Using **Python, Pandas, NumPy, and Matplotlib**, the dataset was cleaned, transformed, analyzed, and visualized. The analysis includes calculating total revenue, identifying the products generating the highest and lowest sales, determining the category contributing the most revenue, analyzing monthly sales trends, and identifying the cities with the highest revenue.

The project also calculates the **Average Order Value (AOV)** and the percentage contribution of each category to total revenue. Different visualizations, including line charts and bar charts, were created to make the results easier to understand and communicate.

Based on the analysis, business recommendations were developed around inventory management, product performance, marketing strategies, high-performing categories, sales trends, and city-level performance.

This project demonstrates practical skills in **data cleaning, exploratory data analysis (EDA), data aggregation, visualization, and business intelligence using Python**. It also provides experience in converting raw sales data into actionable insights that can support data-driven business decisions.
